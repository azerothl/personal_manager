# Personal Manager

Cette application Next.js et TypeScript affiche un CV composé de rubriques telles que les expériences, les diplômes, les compétences et les langues. La page d’accueil assemble ces rubriques dans le composant CV.

## Démarrage

Installer les dépendances avec Yarn depuis la racine, puis exécuter yarn dev. Les pages se trouvent dans pages/ et les composants des rubriques dans components/.
